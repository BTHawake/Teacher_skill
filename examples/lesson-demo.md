# 进位计数制

## 为什么需要不同的进制？

计算机只认识 0 和 1，但人习惯十进制。**进制只是同一数量的不同写法**，就像"12 个苹果"可以写成 `12`（十进制）、`1100`（二进制）或 `C`（十六进制）。

::: definition 基数
一个进制允许使用的数字个数叫作**基数**。十进制基数为 10，二进制基数为 2，十六进制基数为 16。
:::

### 位权展开

任意 $r$ 进制数 `d_n ... d_1 d_0` 的值：

```text
值 = d_n × r^n + ... + d_1 × r^1 + d_0 × r^0
```

::: example 十进制 345
`345 = 3×10² + 4×10¹ + 5×10⁰ = 300 + 40 + 5`
:::

## 三种转换方法

| 转换 | 方法 | 口诀 |
|------|------|------|
| 二 → 十 | 按位权展开求和 | 每位乘权重再相加 |
| 十 → 二 | 整数除 2 取余，小数乘 2 取整 | 除基取余，逆序排列 |
| 二 ↔ 八 / 十六 | 3 位 / 4 位一组 | 分组直接替换 |

::: warning 常见错误
不要混淆**基数**和**位权**：基数是一个进制的"底"，位权是某个位置上的权重（基数的幂）。
:::

### 例：十进制 200 转二进制

```text
200 ÷ 2 = 100 ... 0
100 ÷ 2 =  50 ... 0
 50 ÷ 2 =  25 ... 0
 25 ÷ 2 =  12 ... 1
 12 ÷ 2 =   6 ... 0
  6 ÷ 2 =   3 ... 0
  3 ÷ 2 =   1 ... 1
  1 ÷ 2 =   0 ... 1
逆序读取：11001000
```

::: tip 快速验算
`11001000₂ = 128 + 64 + 8 = 200`。转换完用位权展开验算一遍，能拦住大部分粗心错误。
:::

## 练习

### 练习 1：二进制 11010110.101 转十六进制

::: answer 参考答案
整数部分从右往左每 4 位一组：`1101 0110` → `D6`；小数部分从左往右每 4 位一组：`1010` → `A`。答案是 **D6.A**。
:::

### 练习 2：十进制 200 转二进制

::: answer 参考答案
按"除 2 取余、逆序排列"得到 **11001000**。验算：128+64+8=200。
:::

### 练习 3（判断）：八进制 745 转二进制

::: answer 参考答案
每位八进制展开成 3 位二进制：`7→111`、`4→100`、`5→101`，所以是 **111100101**。
:::

::: summary 本单元小结
- 进制是同一数量的不同写法，核心是**位权展开**。
- 二→十：按位权求和；十→二：除基取余。
- 二↔八/十六：3 位 / 4 位分组。
:::
