# 单元讲义模板（v3.0）

> 用法：复制本模板，替换 `[占位符]`，保存到 `讲义/{课程}/unit-XX-{标题}.md`，
> 然后运行 `python scripts/lesson_html.py build ...`。
>
> 只写本单元**实际讲过**的内容；不要注入未讲过的知识。

```markdown
---
course: [课程名称]
unit: [单元序号，如 4]
title: [单元标题]
date: [YYYY-MM-DD]
status: [已完成 / 进行中 / 待复习 / 待学]
kind: lesson
tags: [标签1, 标签2]
objectives:
  - [学完能做什么 1]
  - [学完能做什么 2]
review_at: [YYYY-MM-DD，可选]
state_id: [learning-state 里的 id，如 U4，可选]
sources:
  - [教材/章节/链接]
description: [一句话摘要，显示在目录卡片]
---

# [单元标题]（脚本会去掉这一行，页面标题已显示）

## 为什么学这个

[用 1-2 段大白话说明用途/问题，不要堆术语。]

## 核心概念

::: definition [概念名]
[一句话定义 + 一个反例/边界。]
:::

[讲解正文。每个概念配一个例子，必要时加表格/代码/示意图。]

::: example [例子名]
[具体例子，最好用用户熟悉领域。]
:::

## 易错点

::: warning [易错点标题]
[常见错法 + 正确做法。]
:::

## 练习

### 练习 1（概念辨析）

[题目]

::: answer 参考答案
[答案 + 为什么]
:::

### 练习 2（应用）

[题目]

::: answer 参考答案
[答案 + 步骤]
:::

### 练习 3（迁移）

[题目]

::: answer 参考答案
[答案 + 思路]
:::

::: summary 本单元小结
- [要点 1]
- [要点 2]
- [要点 3]
:::

> [下一单元预告 / 一句鼓励]
```

## 内容检查清单

- [ ] 学习目标可检测（能做题/能解释），不是"了解XX"
- [ ] 至少一个正例 + 一个反例
- [ ] 练习 3 题：概念 / 应用 / 迁移
- [ ] 答案折叠，且解释为什么
- [ ] 标注来源；未联网核验的内容写明
- [ ] 没有密钥、隐私、聊天原文
- [ ] 生成后打开 HTML 检查渲染
